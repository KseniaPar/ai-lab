To implement an in-memory ask rate limit per user, we can use a `ConcurrentHashMap` to store the last time each user asked a question and then check if the current time is within the allowed time frame.

Here's how you can do it:

1. **Add Configuration Property:**
   Add a configuration property for the rate limit in your `application-local.yml`.

   ```yaml
   app:
     ask:
       rate-limit-per-minute: 5
   ```

2. **Create Rate Limit Service:**
   Create a service to handle the rate limiting logic.

   ```java
   package com.ailab.qa;

   import org.springframework.beans.factory.annotation.Value;
   import org.springframework.stereotype.Service;

   import java.time.LocalDateTime;
   import java.util.concurrent.ConcurrentHashMap;

   @Service
   public class RateLimitService {

       private final ConcurrentHashMap<String, LocalDateTime> lastAskTimeMap = new ConcurrentHashMap<>();
       private final int rateLimitPerMinute;

       public RateLimitService(@Value("${app.ask.rate-limit-per-minute}") int rateLimitPerMinute) {
           this.rateLimitPerMinute = rateLimitPerMinute;
       }

       public void checkRateLimit(String userId) throws IllegalStateException {
           LocalDateTime lastAskTime = lastAskTimeMap.get(userId);
           if (lastAskTime != null && !isWithinRateLimit(lastAskTime)) {
               throw new IllegalStateException("Слишком много запросов в минуту. Пожалуйста, подождите.");
           }
           lastAskTimeMap.put(userId, LocalDateTime.now());
       }

       private boolean isWithinRateLimit(LocalDateTime lastAskTime) {
           return LocalDateTime.now().isBefore(lastAskTime.plusMinutes(1));
       }
   }
   ```

3. **Integrate Rate Limiting in Q&A Service:**
   Integrate the rate limiting service into your Q&A service.

   ```java
   package com.ailab.qa;

   import org.springframework.beans.factory.annotation.Autowired;
   import org.springframework.stereotype.Service;

   @Service
   public class QaService {

       private final RateLimitService rateLimitService;

       @Autowired
       public QaService(RateLimitService rateLimitService) {
           this.rateLimitService = rateLimitService;
       }

       public String answerQuestion(String userId, String question) throws IllegalStateException {
           rateLimitService.checkRateLimit(userId);
           // Your existing logic to answer the question
           return "Answer: " + question; // Placeholder for actual answer logic
       }
   }
   ```

4. **Update Controller:**
   Ensure that your controller calls the `answerQuestion` method from the `QaService`.

   ```java
   package com.ailab.qa;

   import org.springframework.beans.factory.annotation.Autowired;
   import org.springframework.web.bind.annotation.*;

   @RestController
   @RequestMapping("/api/qa")
   public class QaController {

       private final QaService qaService;

       @Autowired
       public QaController(QaService qaService) {
           this.qaService = qaService;
       }

       @PostMapping("/ask")
       public String askQuestion(@RequestParam String userId, @RequestBody String question) throws IllegalStateException {
           return qaService.answerQuestion(userId, question);
       }
   }
   ```

With these changes, you have implemented an in-memory rate limit per user for asking questions. If a user asks too many questions within a minute, they will receive an `IllegalStateException` with the Russian message "Слишком много запросов в минуту. Пожалуйста, подождите."
